# Lean proofs

Lean 4 proofs of the statements the 2024 thesis makes on its own authority (the two rows of
[`../thesis/CLAIMS.md`](../thesis/CLAIMS.md) without a Lean name are a clarification and a
Python computation), of the corrections made in the revised edition, of the October 2026
research, and of the bridges to `openai/math`. The status of each statement and the name of its
proof are in `CLAIMS.md`.

Toolchain `leanprover/lean4:v4.35.0`, Mathlib `v4.35.0`.

## Build

```text
cd lean
lake exe cache get
lake build
```

`lake build` checks every proof; once the Mathlib cache is in place it takes a few minutes, most
of it in the `native_decide` checks of `Witt` and `SteinerInstances`.
`lake build HypergraphDualization.Connections` (or any other module) checks one module and its
imports.

On Windows, `lake exe cache get` and `lake build` run from the repository's own path (checked
2026-10-21 with long paths disabled; no drive mapping is needed). Where `cache.mathlib.org` is unreachable, `MATHLIB_CACHE_DEBUG_USE_LEGACY=1` reads the
same cache from Mathlib's Azure storage account.

## Trust base

Track S's relabelling foundation is in `Symmetry` (`tr_eq_pimg_iff`, `dual_pimg`)
and `Algorithm` (`fkAR_pimg`). Verdicts are invariant even when the split rule
changes; node counts are not claimed invariant (research Proposition 4.21).

General theorems depend only on the axioms `propext`, `Classical.choice` and `Quot.sound`.
Facts about named finite instances are proved by evaluation with `native_decide`, which also
trusts the Lean compiler; their docstrings and module headers say so. `Axioms.lean` lists every
cited name in one of the two classes, and `lake build` fails if a name is in the wrong one
(`#assert_standard_axioms`, `#assert_evaluation`); a `sorry` fails it too. CI also rejects any
`sorry` in the sources. A kernel-only check (`decide +kernel`) succeeds on the smallest instances but did not finish
on the larger ones within 40 minutes.

## Regenerating the generated modules

From the repository root, with the Python package importable:

```text
python lean/tools/gen_instances.py     # Data.lean from data/instances
python lean/tools/gen_trees.py         # TreeFacts.lean from results/*.fk-a.modified.json
python experiments/witt_m11.py --lean  # WittData.lean from data/instances/w11.json
python experiments/steiner_selftr.py --lean  # SteinerData.lean: PG(2,4), S(4,7,23)
```
